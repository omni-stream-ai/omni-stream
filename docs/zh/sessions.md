# 会话

本文定义会话功能与交互规则。即时请求默认在当前会话完成；对话结束后仍需按时执行的委托见[长期任务](automations.md)。

用户通过会话与系统 Agent 对话。系统 Agent 通过内置和用户自定义的 skill 提供功能，内置能力见 [内置 skill](builtin-skills.md)；客户端以对话时间线展示各步骤及执行过程。

## 外部 Agent 协作

用户创建的专属助手可通过 @ 显式调用，创建、插件范围和长期任务绑定规则见[命名 Agent](agents.md)。下文未指定助手时沿用默认引擎选择。

收集信息、读取资料、分析项目或修改代码等超出内置工具能力的请求，可委派给已配置的外部 Agent。这是系统的委派能力。

| 功能 | 行为 |
| --- | --- |
| 选择 Agent | 使用目标项目配置中的 Agent；交互 CLI 由用户选择，当前 HTTP 对话入口默认选择列表中的第一个。没有可用 Agent 时提示配置。 |
| 传递需求 | 携带原始请求、目标项目和已有上下文；操作范围以用户请求为准，询问项目内容不应扩展成代码修改。 |
| 执行反馈 | 支持流式输出时展示文本和进度，完成结果回到原会话；后台执行展示任务状态。 |
| 用户响应 | Agent 发起的审批、选择或补充输入，按适配器能力交给用户处理，统一放在消息输入框上方。 |
| 继续对话 | 支持会话恢复时继续原 Agent 上下文；CLI 使用 `agent continue <内容>`，当前执行结束后才能继续。 |
| 取消与失败 | 允许取消执行并展示结果；认证、网络或格式错误应明确报告，不因这些错误自动改用其他 Agent。 |

插件配置也可直接启动[Agent 配置协助](plugins.md#agent-配置协助)，使用 Core 的 Agent 配置和独立工作目录，后续消息直接交给该 Agent；凭据只在插件配置页填写。

长期任务可在每次执行前发起[逐次确认](automations.md#每次执行前确认)。确认卡片链接到本次专属讨论会话，用户可与任务的 Agent 调整委托内容，再通过卡片明确确认；普通聊天回复不视为执行批准，讨论不会提前执行任务。

连续对话与交互审批可使用 Codex App Server；其他 Agent 的能力取决于适配器。配置、审批范围和取消行为见[适配器说明](adapters.md)。

不同会话使用各自的执行线程，同一会话连续对话保留上下文。终端占用原线程时，按[占用与分支规则](adapters.md#执行生命周期)创建独立分支并记录；同一 OmniStream 执行作用域内仍禁止并发启动。

## 消息展示

- 使用 Markdown 渲染，适合图示的内容优先用图表达。扩展表达形式时，需同时提供提示词说明和客户端渲染支持。
- 代码块支持语法高亮和复制。

### Agent 调用展示

- 系统 Agent 的回复作为普通会话消息展示。
- 调用外部 Agent 时，在时间线中显示独立调用步骤，标明 Agent 名称、目标项目和本次任务。
- 外部 Agent 的进度、输出和结果归在对应调用步骤下，明确标注来源，与系统 Agent 的回复区分。
- 执行步骤按实际操作显示命令、文件修改、工具调用、资料搜索、计划或上下文延续；同一 turn 内相同操作 ID 的开始、输出片段和结束合并展示，完成事件提供的汇总输出替代片段。计划更新展示该轮最新版本。会话同步、用量统计及重复消息等协议事件不计为执行步骤，完整记录仍保留在折叠的“原始事件”中；未知事件提供通用摘要与原始记录，不推断不存在的执行结果。展开操作可查看工作目录、文件及变更、计划条目、调用参数、输出、退出码和错误；正常结束不额外标记成功，失败和执行中的操作保留提示。
- 调用步骤正常结束后不显示状态标签，包含内部 `succeeded`、`completed` 和 `unverified` 记录；测试与验收结论保留在结果正文中。仅在排队、执行中、等待用户或审核，以及失败、阻塞、取消、暂停、中断等需要关注时显示状态；待响应请求优先显示“等待用户”。
- 外部 Agent 完成后，系统 Agent 按需要总结；结果已能直接回答用户时，不重复复述。

### 图片预览

消息和输入区共用图片预览组件：

- 点击图片全屏查看；通过 Enter 或鼠标点击展开、还原控件切换。
- 方向键或鼠标拖动平移，滚轮缩放。
- 同一条消息包含多张图片时，显示底部缩略图和两侧切换按钮；没有上一张或下一张时隐藏对应按钮。

## 待处理操作

审批、选择等需要用户响应的操作，统一放在消息输入框上方，标明所属 Agent；来自外部 Agent 的请求同时标明对应调用步骤。

审批请求应说明具体请求类型，例如执行命令、修改文件或申请额外权限；如果 Agent 没有提供具体原因，界面明确显示“未提供具体原因”，不得使用看似具体但实际推测出的理由。

### 审批模式

审批模式选择器放在输入框内部底部左侧，显示当前选项；未配置时选择“默认策略”。

| 模式 | 行为 |
| --- | --- |
| 默认策略（default） | 沿用外部 Agent 自身的审批与沙箱配置，需要审批时交给用户。 |
| 内部允许（safe） | 允许在工作区沙箱内执行，Agent 需要额外权限时发起审批；不代表所有操作都免审批。 |
| 完全允许（all） | 不设置工作区沙箱限制，自动批准支持直接批准的权限请求；不能代替用户填写具体回答。 |

审批模式按会话独立保存，切换或重新打开会话时恢复该会话的选择；新会话使用“默认策略”，不继承其他会话的选择。修改仅影响当前会话后续的 Agent 执行，不影响其他会话或正在进行的执行。

以上模式行为以 Codex App Server 接入为准，其他适配器以实际支持为准；模式不代替任务计划批准。审批模式按会话保存，模型选择由所有会话共享。

## 用户输入

使用 Lexical 编辑 Markdown 原文，不实时渲染。附件、项目引用和输入控件均放在输入框边框内。

| 功能 | 行为 |
| --- | --- |
| 按钮添加附件 | 在输入框内部顶部展示缩略图，右上角提供删除按钮。 |
| 粘贴附件 | 在粘贴位置插入 `[Image1]`、`[File1]` 等引用，颜色区别于普通文字，整体选中或删除。 |
| 附件预览 | 图片点击后使用共用预览组件；按钮添加和粘贴的图片共享预览列表，可左右切换。非图片附件仅显示通用缩略图，暂不支持预览。 |
| 引用项目 | 输入 `@` 模糊搜索已知项目；输入 `@/` 或 `@~` 开头的路径时调用 Core 搜索其他文件夹，选中后高亮引用，整体选中或删除。候选项使用输入框内的弹出列表展示，不依赖 Lexical 专用插件。 |
| 模型设置 | 输入框内部底部左侧提供一个分层下拉菜单：provider → 模型 → 思考等级；没有思考等级的模型可直接选中。有等级时选择具体等级或默认思考。选中值由后端全局持久化，切换会话或重启后沿用，所有会话共享；只影响后续系统 Agent 请求，外部 Agent 仍使用自身配置。 |
| 斜杠命令 | `New`、`Clear` 均新建会话；`Rename` 重命名当前会话。候选项默认选中第一项，支持上下键、Enter、Escape 和鼠标选择。 |
| 会话管理 | 列表行末的“更多”菜单提供重命名、归档和删除；重命名在行内编辑，删除用红色区分。归档后不显示在默认会话列表中，删除会移除会话消息、设置、外部 Agent 调用记录及关联的 Agent session。 |
| 发送与换行 | Enter 发送，Shift + Enter 换行。联想浮窗打开时，Enter 优先选择当前候选项。 |

## 配置与验证

- 展开 provider 时从其 `base_url/models` 接口获取模型列表，后端缓存 5 分钟，支持手动刷新；无数据且正在加载时显示骨架屏，空列表和失败分别提示，失败后仅手动重试。
- 思考等级按 provider 配置，不按具体模型配置。默认提供 `low`、`medium`、`high`；provider 可用 `reasoning_efforts` 覆盖默认值。模型接口若明确返回 provider 级思考等级则优先使用；`xhigh`、`extra high` 等特殊等级只有明确声明时显示。配置示例见[模型配置](configuration.md#模型配置)。
- 自定义 skill 从全局状态目录的 `skills/<名称>/SKILL.md` 和目标项目的 `.omnistream/skills/<名称>/SKILL.md` 加载，每次请求读取。
- 附件单个不超过 10 MB，每条消息最多 20 个、合计 20 MB；图片和文本交给管理模型，外部 Agent 可通过保存的文件读取。其他文件格式能否直接交给模型取决于 provider 支持。
- 图示支持 Mermaid 代码块，提示词与渲染端使用同一约定。
- 执行 `cargo test -p omnistream`、GUI 的 `typecheck` 和 `build`；浏览器验证先构建 Core，再运行 `pnpm --filter @omnistream/gui test:e2e`。测试使用独立数据目录、模拟模型及 Agent，不调用真实模型；可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定浏览器。
