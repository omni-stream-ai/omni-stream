# 内置 skill

内置 skill 指导系统 Agent 理解请求并调用工具。目前提供通用对话、长期委托与项目管理 skill。

## 通用对话与长期任务

内置管理 skill 区分即时请求和长期委托。即时查询、资料分析和开发在当前会话执行，不创建用户任务；定时、周期执行或持续检查的长期委托使用[长期任务](automations.md)规则和 `*_automation` 工具。工作目录是可选执行上下文，不是通用委托的前提。

[只读网页访问](sessions.md#只读网页访问)已预先授权，直接使用可用读取工具，不额外询问。

长期任务可配置[逐次确认](automations.md#每次执行前确认)。管理模型可保存确认设置；讨论 Agent 仅可通过绑定本次的 automation_confirmation 工具调整目标文本，最终批准由用户完成。

项目管理继续支持登记、定位、重命名、删除和归档已有目录；名称歧义时澄清，不猜测路径。会话继续支持重命名、归档和删除。

已安装并连接的应用由原生插件工具读取和操作，不需要先委派外部 Agent。实际工具、参数、凭据及写入审批规则见[插件市场](plugins.md)；账号连接只能在市场中显式配置，管理模型不接触令牌；获取令牌可通过[Agent 配置协助](plugins.md#agent-配置协助)启动独立会话，用户仍在配置表单填写凭据。长期任务默认交付渠道不因插件安装改变。

Agent 执行指令见 [SKILL.md](../../skills/omnistream-project-management/SKILL.md)，以内置方式加载。
