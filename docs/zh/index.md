# 项目文档

这里是项目知识入口。Agent 工作流程和文档维护要求见 [AGENTS.md](../../AGENTS.md)。

## 全局约定

- 已确认的行为与约束用于指导实现；现状说明用于记录已实现能力和限制，待讨论方案不作为实施依据。
- 用户明确要求的规范变更在授权范围内生效并同步文档；其余情况遵循全局规则及模块引用的通用规则，模块特例必须明确注明适用范围和依据。
- 文档之间有未解释的冲突时先澄清，不按文件位置或新旧自行覆盖。文档与代码不一致时按协作约定处理。
- 文档按实际需要组织，可在一个文件内说明完整模块；需要独立维护时再拆分，并更新下方索引。相关模块通过相对链接引用共用规则。
