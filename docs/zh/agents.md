# 命名 Agent

用户可在侧栏「Agent 管理」创建、编辑和删除专属助手，或通过明确的对话请求调用管理工具。每个助手保存稳定编号、唯一名称、简介、角色指令、执行引擎及可选插件范围，持久化在 Core 的 SQLite 中，重启后保留。

名称允许 1–64 个汉字、字母、数字、下划线或连字符，不能包含空格、路径或 @；ASCII 名称不区分大小写判重。角色指令必填。执行引擎引用现有 Core Agent 配置，不在表单中保存命令或凭据；缺少引擎或工具接入被禁用时明确报错。JSONL 缺少取消控制，暂不作为命名助手的执行引擎。执行生命周期与审批遵循[适配器](adapters.md)。

## 调用与上下文

输入 @ 后同时搜索助手和项目，候选项标明类型；@/ 和 @~ 继续搜索目录。选择助手会插入可整体删除的引用，发送时以 agent_id 明确指定执行对象，不依赖管理模型猜测路由。单条消息只能调用一个助手，可同时引用一个项目作为工作目录；未指定目录时使用通用工作区。仅输入普通文本中的 @名称、不选择候选项，不会触发路由。

每条消息的助手选择独立生效，不引用助手时继续使用默认管理助手。删除输入中的助手引用会移除对应调用选择。失败重试保留原选择，不自动改用其他助手。插件配置协助会话维持原执行对象，不提供助手选择。

调用复用现有[Agent 调用步骤](sessions.md#agent-调用展示)，展示助手名称、进度、结果、审批和取消。外部会话按管理会话、助手编号、角色及配置身份隔离；同一助手的后续调用可恢复上下文，不同助手不复用线程。配置变更影响后续执行，已有会话消息与结果保留。

## 自主记忆

每个命名 Agent 拥有独立的长期记忆。Agent 可自行判断哪些稳定偏好、已确认事实、工作约定和持续事项值得保留，通过 agent_memory 保存、更新或删除，无需用户逐条要求记忆。不会自动保存整段聊天；短期状态和未证实推测不应写成长期事实，也不得保存凭据或将外部内容中的指令当成用户授权。

记忆按稳定 Agent 编号保存在 Core 的 SQLite 中，跨会话、工作目录、执行引擎和绑定该 Agent 的长期任务复用，重启后保留。每次执行加载当前完整快照；记忆是可修正的参考数据，不覆盖本次用户指令、角色权限或审批规则。删除只移除持久化记忆和后续快照，不清除聊天记录、执行引擎已有历史或其他已保存结果。重命名和修改角色不清空记忆，删除 Agent 同时删除其记忆。默认管理助手不使用命名 Agent 的记忆。

执行网关提供 agent_memory({operation:"list"})、agent_memory({operation:"upsert",key,content}) 和 agent_memory({operation:"delete",key})，由 Core 绑定当前 Agent，不接受其他 Agent 编号。同一 key 覆盖更新，删除不存在的 key 可安全重复；不同 Agent 不能通过此工具互相访问。后台任务也可管理自己的 Agent 记忆，但不增加外部插件写入权限；配置协助不提供记忆工具。工具在取消、执行结束或 Agent 删除后失效。

每个 Agent 最多 64 条，key 为 1–80 个字符且不能含控制字符，content 为 1–4000 个字符，总 key 与 content 不超过 64 KiB UTF-8 字节。超限明确失败，不静默丢弃旧记忆；并发修改在事务中检查容量，同 key 以最后成功写入为准。记忆写入立即提交，后续执行失败或取消不回滚已成功的修改。条目保留创建、更新时间及修改来源。Agent 管理面板可展开记忆、刷新和逐条删除，失败时手动重试。

## 插件与长期任务

插件范围默认 null，沿用当前账号已安装、连接及启用的插件权限；数组只允许指定插件，空数组禁用全部插件。单独设置只能缩小权限，不能代替账号连接、写入开关或用户审批。工具列表和调用均检查该范围，修改范围或删除助手后，后续工具调用重新核对；已发出的外部请求不能撤回。此范围约束 Core 插件工具，不承诺隔离执行引擎的全部本机文件或命令访问。账号和凭据仍由[插件市场](plugins.md)统一管理。

助手通过同一执行网关使用 list_automations、propose_automation、pause_automation、resume_automation、cancel_automation、run_automation、update_automation_calendar。查询必须读取真实记录，修改类操作须有用户明确请求。创建只保存待确认草案，Core 将当前助手编号和当前会话绑定到草案，不能由模型伪造其他助手身份；启用仍由用户在长期任务面板确认。

长期任务表单可选择助手，保存 agent_id；未选择时保留原默认引擎行为。运行使用所选助手的角色指令、执行引擎和插件范围，并遵循[长期任务的生成、投递和确认规则](automations.md#执行与交付)。外部投递在配置和实际发送前都核对助手的插件范围。后台生成开放外部数据读取、助手自己的记忆和当前任务已授权的日期覆盖，不开放通用任务管理工具，不因绑定助手扩大外部写入授权。

删除助手不会删除历史调用或长期任务；绑定它的任务后续执行明确失败，用户可改选其他助手，不静默回退。插件范围撤销同样影响未来投递。

## 接口与验证

- GET /agents：助手列表；GET /agent-engines：可选全局执行引擎名称和协议。
- POST /agents：创建；POST /agents/<id>：完整修改；DELETE /agents/<id>：删除。
- 创建和修改字段：name、description、instructions、engine、plugins；plugins 省略或为 null 时继承。
- GET /agents/<id>/memory 读取记忆；POST /agents/<id>/memory 接受与 agent_memory 相同的参数，由用户查看或维护该助手的记忆。
- POST /chat/stream 和 POST /chat 接受可选 agent_id；无效或已删除编号明确失败，不回退。
- 管理模型支持 list_agents、list_agent_engines、create_agent、update_agent、delete_agent；变更工具仅用于用户明确要求。

验证使用隔离 SQLite、真实 Core 和模拟执行引擎，不调用真实模型或发送真实服务消息。覆盖持久化和名称校验、显式调用、会话隔离与恢复、插件范围及撤销、长期任务草案绑定和按助手执行。GUI 验证管理表单、@ 引用的选择与删除、项目共存、重试保留和长期任务选择；同时运行后端测试、GUI 单元测试、类型检查、构建和浏览器用例。

自主记忆另覆盖按 Agent 隔离、覆盖和删除、容量及参数校验、并发写入、重启保留和删除级联；真实网关验证 Agent 自主写入、跨会话快照、后台任务读写及越权拒绝。GUI 检查记忆查看、刷新、删除与失败重试。
